# landbot-lab-demos

Demos privadas de Landbot preparadas para prospectos concretos (piloto outbound de Agent Studio).
Se publican en `https://demos.landbot-lab.dev/<slug>/` con `noindex` y `robots.txt` que bloquea todo.
Cada demo lleva el rótulo "Demo preparada por Landbot para <Empresa>" y nunca se embebe en sitios del prospecto.
